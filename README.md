This Inventory Management System is a menu-driven Java application developed as part of the Java Programming mini project to demonstrate core object-oriented programming concepts and file handling. The system allows users to add, display, and search products using a unique product ID, calculate the total stock value, and store inventory data persistently using file operations. The project is implemented using classes and objects, constructors, access modifiers, method overriding, string handling, buffered file streams, and proper exception handling to ensure error-free execution. The application follows a modular design for better readability and maintainability and fulfills all academic requirements specified in the assignment guidelines.
